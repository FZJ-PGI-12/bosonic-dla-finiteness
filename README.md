# bosonic-dla-finiteness

A Python library for deciding whether the dynamical Lie algebra (DLA) of a bosonic quantum system is finite-dimensional.

Given a set of control Hamiltonians expressed as normal-ordered bosonic operators, the library decomposes the generators into canonical subspaces of the Weyl algebra and runs a table-based classification algorithm that either certifies finite-dimensionality, detects infinite-dimensionality, or identifies generators that require further analysis.

## Background

Determining the exact dynamics of a given system is a central goal in most areas of physics, especially in quantum mechanics. There, the evolution is determined by a unitary time-evolution operator $U(t)$ defined by the differential equation $$\frac{\mathrm{d}}{\mathrm{d}t}U(t)=-\mathrm{i}H(t)U(t)$$ together with the initial condition $U(0)=\mathds{1}$, where $H(t)$ is the Hamiltonian of the system. A closed form solution for $U(t)$ is usual unattaianble, in particular when the Hamiltonian is time-dependent. In such cases, one often resorts to approximate methods like the truncation of the Magnus expansion or Lie-Trotter-Suzuki like formulas. Nontheless, approaches like the Wei-Norman method offer, in certain cases, analytic solutions, where the idea is to factorizes the time-evolution operator into a finite product of exponentials [Wei:Norman]. For this, one decomposes the Hamiltonian $-iH(t)$ into a sum of linearly independent skew-hermitian operators $G_j$ and suitable time-dependent scalar functions $u_j(t)$, often called control functions, such that $$-iH(t)$=\sum_{j\in\mathcal{J}} u_j(t) G_j$$. The important restriction that allows to find a manageable expression of $U(t)$ in the form of $$U(t)=\prod_{k\in\mathcal{K}} \exp(f_k(t) G_k)$$ is the condition that the dynamical Lie algebra $\mathfrak{g}=\langle\mathcal{G}\rangle_{\mathrm{Lie}}$ generated by $\mathca{G}=\{G_j\}_{j\in\mathcal{J}}$ is finite-dimensional.


Recently, a new framework was proposed to identify classes of Hamiltonians for which this method is applicable by analyzing the dimensionality of the dynamical Lie algebras through a suitable
characterization of their generating terms [Bruschi:Xuereb:Zeier]. Here, we report an algorithm aiding in deciding whether a dyanmical Lie algebra is finite-dimensional and therefore a factorization, in principle, possible. For this, we focus on bosonic systems with $n$ modes, where the Hamiltonians of interest can be expressed as a finite polynomial of so called generators; for a detaile explanation see below.  where most Hamiltonians can be written as a finite polynomial in the creation and annihilation operators $a^\dagger_k$, $a_k$ satisfying the canonical commutation relations $[a_k, a^\dagger_j] = \delta_{kj}$. The corresponding infininte-dimensional complex associatve algebra is the Weyl algebra [Dixmier]. There, any Hamiltonian can be expressed in terms of normal-ordered monomials

## Core concepts

The **Weyl algebra** $A_n$ of $n$ bosonic modes is the unital associative infinite-dimensional Lie algebra obtained from the creation and annihilation operators $a^\dagger_k$, $a_k$, which satisfy the canonical commutation relations $[a_k, a^\dagger_j] = \delta_{kj}$. A basis of this space is given by the **normal-ordered monomials** $a^\gamma = (a^\dagger)^\alpha (a)^\beta=(a_1^\dagger)^{\alpha_1}\ldots(a_n^\dagger)^{\alpha_n}a_1^{\beta_1}\ldots a_n^{\beta_n}$, which are indexed by a multi-index $\gamma = (\alpha, \beta) \in \mathbb{N}_{\geq0}^{2n}$. Their degree is determined by $|\gamma| = \sum_j (\alpha_j + \beta_j)$.

The Weyl algebra must be restricted to its real skew-hermitian subalgebra $\hat{A}_n$, defined by all elements that satisfy $p^\dagger=-p$, because the unitary time-evolution operator is given by a time-ordered exponential of a skew-hermitian operator. There a possible basis is given by the, as generators denoted, elements

$$g_+^{(\alpha,\beta)} = \mathrm{i}\bigl(a^{(\beta,\alpha)} + a^{(\alpha,\beta)}\bigr), \qquad g_-^{(\alpha,\beta)} = a^{(\beta,\alpha)} - a^{(\alpha,\beta)}$$

Each adjoint pair $\{(\alpha,\beta), (\beta,\alpha)\}$ contributes one basis element, so $\gamma$ must be the canonical (lexicographically larger) representative: $(\alpha,\beta) \geq (\beta,\alpha)$ for $g_+$, and strictly $(\alpha,\beta) > (\beta,\alpha)$ for $g_-$, which vanishes when $\alpha = \beta$. Note that `BosonicGenerator` rejects a non-canonical index.

To distinguish physically meaningful and operational distinct classes of operators, we decompose the skew-hermitian Weyl by the following **vector-space decomposition** $\hat{A}_n=\hat{A}_n^0\oplus \hat{A}_n^1\oplus\hat{A}_n^2\oplus \hat{A}_n^\mathrm{om}\oplus \hat{A}_n^=\oplus \hat{A}_n^\perp$. The individual subspaces are defined as follows:

| Subspace | Condition on $g_\sigma^{(\alpha,\beta)}$ | Example |
|----------|------------------------------------------|---------|
| $\hat{A}_n^0$ | degree 0 (constant), or degree 2 with $\alpha = \beta$  | Number operator $\mathrm{i}a_1^\dagger a_1 |
| $\hat{A}_n^1$ | degree 1 | Displacements $a_1-a_1^\dagger$ |
| $\hat{A}_n^2$ | degree 2, $\alpha \neq \beta$ | Two-mode squeezing $\mathrm{i}(a_1a_2+a_1^\dagger a_2^\dagger)$; Single-mode squeezing $a_1^2-(a_1^\dagger)^2$; mode-mixer $a_1a_2^\dagger a - a_1^\dagger a_2$ |
| $\hat{A}_n^=$ | $\alpha = \beta$, degree $\geq 4$ | Kerr-type $(a_1^\dagger)^2a_1^2
| $\hat{A}_n^{\mathrm{om}}$ | degree $\geq 3$, exactly one mode $k$ with $\alpha_k + \beta_k = 1$, all other modes diagonal ($\alpha_j = \beta_j$) | Optomechanical-like $\mathrm{i}(a_1+a_1^\dagger)a_2^\dagger a_2$ |
| $\hat{A}_n^\perp$ | everything else (orthogonal complement of $\hat{A}_n^0\oplus \hat{A}_n^1\oplus\hat{A}_n^2\oplus \hat{A}_n^\mathrm{om}\oplus \hat{A}_n^=$) | SPDC $a_1a_2^\dagger a_3^\dagger -a_1^\dagger a_2 a_3$ |

Given a set of generators $\mathcal{G}=\{g_{\sigma_k}^{\gamma_k}\}_{k\in \mathcal{K}}$ can be disjointly decomposed into the sets $\mathcal{G}^K:=\mathcal{G}\cap \hat{A}_n^K$, where $K\in\{0,1,2,\mathrm{om},=,\perp}$.

Another important class of operators are the **free Hamiltonians**, which are diagonal degree-two elements of the form $X = \sum_k x_k (i a^\dagger_k a_k)$, where $x_k$ are positive frequencies. We denote a set collecting threse by the symbol $\mathcal{F}$. The individual free Hamiltonians are stored as coefficient vectors $x \in \mathbb{R}^n$. For deciding whether a given dynamical Lie algebra is finite-dimensional, only $\mathrm{span}\,\mathcal{F}$ matters, so the algorithm first reduces $\mathcal{F}$ to a basis $\mathcal{F}'$ of that span. The map $\chi_{\mathcal{F}}(\gamma) = \bigl(\chi_{X^{(1)}}(\gamma), \ldots, \chi_{X^{(m)}}(\gamma)\bigr)$ with $\chi_X(\gamma) = \sum_k x_k(\alpha_k - \beta_k)$ vanishes exactly when a generator $g_\sigma^\gamma$ commutes with every $X \in \mathcal{F}$. It therefore detects resonances in the system, which drives the disjoint split $G = G_{\mathrm{co}} \sqcup G_{\mathcal{F}}$, where $G_{\mathcal{F}}$ collects the commuting generators. Diagonal generators always commute, so $G^= = G^=_\mathcal{F}$. A generator in $G^\perp$ with $\chi_{\mathcal{F}}(\gamma) \neq 0$ immediately certifies an infinite-dimensional DLA.

## Hamiltonians of interest

This algorithm works for any bosonic Hamiltonian that can be decomposed as finite polynomial of the following form:

$$-iH(t)=\sum_{\ell\in\mathcal{L}} w_\ell (t) \underbrace{\sum_{k=1}^n \omega_{kl}\,(\mathrm{i}a_k^\dagger a_k)}_{=X^{(\ell)}}+\sum_{q\in \mathcal{Q}} u_q(t) g_{\sigma_q}^{\gamma_q}.$$

It then determines, whether the dynamical Lie algebra 

$$\mathfrak{g}:={\left\langle\left\{X^{(\ell)}\right\}_{\ell\in \mathcal{L}}\cup\left\{g_{\sigma_q}^{\gamma_q}\right\}_{q\in \mathcal{Q}}\right\rangle}_{\mathrm{Lie}}$$

is finite-dimensional, infinite-dimensional, or splits into the vector-space sum of two finite-dimensional subalgebras of $\hat{A}_n^0\oplus \hat{A}_n^1\oplus\hat{A}_n^2\oplus \hat{A}_n^\mathrm{om}\oplus \hat{A}_n^=$ and ${\langle\hat{A}_n^2\oplus \hat{A}_n^\perp\rangle}_{\mathrm{Lie}}$, respectively, which only share an abelian intersection, and where the first component is infinite-dimensional, and the second component is undetermined.


## Usage

```python
from bosonic_dla_finiteness.algebra.finiteness_check import check_finiteness, DimensionResult
from bosonic_dla_finiteness.algebra.free_hamiltonian import FreeHamiltonian
from bosonic_dla_finiteness.operators.monomial import gamma_from_iotas, gamma_from_iotas_sum
from bosonic_dla_finiteness.operators.operator import BosonicGenerator

n = 3
# Drift Hamiltonian with frequencies ω = (1, 2, 3)
F = [FreeHamiltonian([1, 2, 3])]

# Control generators
generators = [
    BosonicGenerator(kind="+", gamma=gamma_from_iotas(n=n, alpha_idx=0)),        # G1
    BosonicGenerator(kind="-", gamma=gamma_from_iotas(n=n, alpha_idx=0, alpha_exp=2)),  # G2
    BosonicGenerator(kind="+", gamma=gamma_from_iotas_sum(n=n, alpha_indices=[0, 1])),  # G2
]

result = check_finiteness(n=n, F=F, generators=generators)
# result.dimension: DimensionResult.FINITE | .INFINITE | .REMAINING
# result.remaining_generators: set of generators requiring further analysis (REMAINING only)
```

### From a YAML config file

**Command line:**

```bash
bosonic-dla examples/example_input.yaml
# Result: Infinite

bosonic-dla -v config.yaml          # -v/--verbose enables debug logging
```

For an inconclusive system the generators that need further analysis are listed:

```
Result: Remaining
Remaining generators (2):
  g_+^((0, 1, 0), (0, 0, 1))
  g_-^((0, 2, 0), (0, 0, 2))
```

**Python API:**

```python
from bosonic_dla_finiteness.io.loader import load_from_yaml
from bosonic_dla_finiteness.algebra.finiteness_check import check_finiteness
from bosonic_dla_finiteness.algebra.free_hamiltonian import FreeHamiltonian

config = load_from_yaml("config.yaml")
generators = [g.to_generator() for g in config.generators]
result = check_finiteness(
    n=config.n_modes,
    F=[FreeHamiltonian(x) for x in config.get_F()],
    generators=generators,
)
```

Generators can be specified either as explicit exponent vectors (`alpha`/`beta`) or in compact `iotas` notation. A full annotated example is provided in [`examples/example_input.yaml`](examples/example_input.yaml):

```yaml
n_modes: 3
omegas: [1.0, 2.0, 3.0]

generators:

  # explicit alpha/beta vectors
  - kind: "+"
    alpha: [1, 0, 0]
    beta:  [0, 1, 0]
    label: "G1"
    description: "g_+(a†_0 a_1)"

  # compact iotas notation (recommended)
  - kind: "-"
    iotas:
      alpha_indices:   [0]
      alpha_exponents: [2]
      beta_indices:    [1, 2]
    label: "G6"
    description: "g_-((a†_0)^2 a_1 a_2)"
```

Each entry requires `kind` (`"+"` or `"-"`), either `alpha`/`beta` or `iotas` (not both), and a `label`. The `description` field is optional. `label` and `description` are documentation only and do not affect the classification.

`omegas` is either a single coefficient vector of length `n_modes`, or a list of such vectors when $F$ contains several free Hamiltonians:

```yaml
omegas:
  - [1.0, 1.0, 1.0]
  - [2.0, 1.0, 1.0]
```

### Constructing multi-indices

```python
from bosonic_dla_finiteness.operators.monomial import gamma_from_iotas, gamma_from_iotas_sum

# Single mode per side: (a†_0)^2  in n=5 modes
gamma_from_iotas(n=5, alpha_idx=0, alpha_exp=2)

# Several modes per side: a†_0 a†_2 a_1  in n=5 modes
gamma_from_iotas_sum(n=5, alpha_indices=[0, 2], beta_indices=[1])
```
